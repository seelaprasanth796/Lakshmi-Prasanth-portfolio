## Lakshmi Prasanth Seela — Portfolio

### Run locally on a MacBook Air (Terminal)

1. Install Node.js 20 or newer (once): download the macOS installer from https://nodejs.org, or with Homebrew run `brew install node`.
2. Open Terminal and go to the unzipped project folder, e.g. `cd ~/Downloads/lakshmi-portfolio`.
3. Install dependencies: `npm install`
4. Start the dev server: `npm run dev` — then open the `http://localhost:...` address it prints.
5. Production build check: `npm run build`
6. Run tests: `npm test`

### Where to edit

- All text, links, projects, skills, experience and education: `src/data/portfolio.ts`
- Project artwork: `src/assets/project-*.jpg`
- Colours, fonts and effects: `src/styles.css`
- Original starter files kept as a backup: `backup/original-template/`
